# 🖥️ Office Simulator - O Desafio do Estagiário (Edição Senac)

> *"Onde o hardware é antigo, mas o estresse é atual."*

Bem-vindo ao **Office Simulator**, um projeto desenvolvido como parte do curso de **Jovem Aprendiz do Senac**. O objetivo? "Ensinar" navegação básica em sistemas operacionais, gerenciamento de arquivos e envio de e-mails de uma forma leve, divertida e totalmente caótica!

![Banner do Jogo](https://cdnb.artstation.com/p/assets/images/images/007/413/479/large/althea-krebelj-pixel-computer.jpg?1505969564)

## 🎯 Sobre o Projeto

Esqueça as aulas chatas de informática básica. Aqui você encarna um estagiário no seu primeiro dia de trabalho na **Compu-Zone**. Sua missão é simples: completar as tarefas do chefe antes que o expediente acabe (e antes que você perca a paciência com o PC lento).

Este simulador "ensina" conceitos como:
- 📂 Navegação entre pastas e diretórios.
- 📧 Simulação de envio de e-mail corporativo.
- ⚙️ Acessar configurações e ferramentas do sistema.
- ⚡ Agilidade e resolução de problemas.

## 🚀 Funcionalidades

- **Simulação de OS Retrô:** Interface nostálgica baseada no Windows 95/98.
- **Sistema de Missões:** 7 tarefas sequenciais que guiam o aprendizado do usuário.
- **Time Attack:** Quanto mais rápido você trabalha, maior seu salário (pontuação).
- **Leaderboard Global (Local):** Um ranking salvo no navegador para competir com os colegas de classe.
- **Responsividade Total:** Funciona no PC da sala de aula e no celular (escondido embaixo da mesa).
- **Easter Eggs:** Tente jogar Minecraft ou deletar o System32 e veja o que acontece. 👀

## 🕹️ Como Jogar

1. **Entre pelo link:** [Compu-OS](https://krl0sed.github.io/Game-Project/).
1. **Faça Login:** Digite seu nome de usuário na tela inicial.
2. **Siga as Instruções:** Uma caixa de texto no topo da tela dirá o que fazer (ex: "Abra o Email").
3. **Seja Rápido:** O tempo está correndo e seus pontos diminuindo!
4. **Ranking:** Ao final, veja se você entrou para o Hall da Fama dos funcionários.

## 🛠️ Tecnologias Utilizadas

Projeto construído com tecnologias web puras (Vanilla), ideal para iniciantes entenderem a base da programação:
- **HTML5:** Estrutura semântica.
- **CSS3:** Estilização retrô, animações e responsividade (Media Queries).
- **JavaScript:** Lógica do jogo, manipulação do DOM e LocalStorage.

## 🔐 Área do Administrador (Spoilers)

Para os instrutores ou chefes do setor:
- Existe uma função para **Zerar o Ranking**.
- Se clicar no ícone **System32** ou no botão de **Limpar Histórico** no ranking, o sistema pedirá uma senha.
- **Senha Secreta:** `poucas pessoas possuem acesso...` 
- *Cuidado: Isso apaga todos os dados salvos no navegador!*
